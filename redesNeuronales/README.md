# Actividad 04 - Perceptron XOR

Contenido:

- `presentacion_xor_kernel.pdf`: presentacion con explicacion del kernel, tabla de transformacion y grafica del plano de separacion.
- `perceptron_xor.js`: codigo JavaScript del perceptron aplicado a XOR con la caracteristica `z = x1*x2`.

Para ejecutar el codigo:

```bash
node perceptron_xor.js
```

El perceptron aprende el plano:

```text
2x + 2y - 5z - 1 = 0
```

donde `z = x1*x2`.

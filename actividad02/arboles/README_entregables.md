# Entregables ACT02 - Arboles y Naive Bayes

Archivos en el repo:

1. `id3_iris_resultado.pdf`: reporte de aplicacion de ID3 a Iris discretizado.
2. `id3_iris_resultado.xlsx`: libro con datos, ganancias de informacion, reglas y matriz de confusion ID3.
3. `reporte_j48_weka_iris.pdf`: reporte de J48 en Weka y ejecucion equivalente en R/RWeka.
4. `naive_bayes_iris.Rmd`: reporte fuente R Markdown para Naive Bayes en Iris.
5. `naive_bayes_iris.html`: HTML generado desde el Rmd.
6. `matriz_confusion_naive_bayes_iris.xlsx`: evaluacion de 20 observaciones con Naive Bayes discreto.
